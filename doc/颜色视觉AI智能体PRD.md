# AI 颜色视觉智能体 - V1.0

## 一、V1.0 产品定位与范围边界

**V1.0 定位**：一个轻量级的"色彩物理+语义"工具。用户通过手机拍照/上传图片，获取精准的颜色数值，并与目标颜色进行比对；同时借助外部 AI 能力，实现基于文字描述的配色图片生成。

**范围硬边界（V1.0 只做这些）**：

**内部接口（自研/本地部署）**：手机色彩校正、颜色取值（拾色器）、图片间颜色比对（色差计算）。

**外部接口（API 调用）**：文生图（Text-to-Image）、基础色彩语义描述（自然语言解读）。

## 二、V1.0 核心功能需求（按接口类型划分）

### 2.1 内部接口模块（自研核心，本地/自有服务器计算）

**设计原则**：保证颜色数据的物理准确性与客观性，不依赖第三方 API，响应速度必须快。

#### 2.1.1 手机颜色校正（Camera Color Calibration）

| 需求编号 | 功能点 | 详细描述 | 优先级 |
| --- | --- | --- | --- |
| **CAL-01** | 颜色视觉校正 | 上传手机拍摄的照片，调用自有校色接口，对拍照、校色进行展现。 | **P0** |

#### 2.1.2 颜色取值（Color Picker）

| 需求编号 | 功能点 | 详细描述 | 优先级 |
| --- | --- | --- | --- |
| **PIC-01** | 单点取色 | 用户在手机相册或相机预览画面上点击任意位置，立即识别该点颜色 | **P0** |
| **PIC-02** | 多格式颜色值输出 | 点击取色后，同时展示 HEX、RGB（0-255）、HSL、CIE-Lab 四种数值，一键复制 | **P0** |
| **PIC-03** | 取色历史记录 | 记录用户最近取色的 20 个颜色值，支持点击重新查看 | **P1** |

#### 2.1.3 图片颜色比对（Image Color Comparison）

| 需求编号 | 功能点 | 详细描述 | 优先级 |
| --- | --- | --- | --- |
| **CMP-01** | 双图上传比对 | 支持用户同时上传"标准图"与"样品图"（或相机实拍），进行颜色比对 | **P0** |
| **CMP-02** | 整体平均色差 (ΔE) | 计算两张图片整体平均 Delta-E 2000 色差值，输出单一数值（例如"ΔE = 2.3"） | **P0** |
| **CMP-03** | ROI 区域比对 | 支持用户在两张图上分别框选特定区域（Region of Interest），仅比对框选区域的色差，排除背景干扰 | **P1** |
| **CMP-04** | 比对结果可视化 | 输出"合格/不合格"提示（由用户自定义 ΔE 阈值，如 ≤2 为合格），并生成色差热力图（差异越大部分颜色越红） | **P1** |

### 2.2 外部接口模块（调用第三方 API，负责语义与生成）

**设计原则**：利用成熟大模型多模态能力，实现"看懂颜色"和"按描述画颜色"，降低自研成本，快速上线。

#### 2.2.1 文生图（Text-to-Image）

| 需求编号 | 功能点 | 详细描述 | 优先级 |
| --- | --- | --- | --- |
| **T2I-01** | 配色描述转图片 | 用户输入文字描述（如"夕阳下的薰衣草田，紫蓝色调"），调用外部文生图 API（如 Midjourney/DALL-E/通义万相），生成对应的色彩场景图 | **P0** |
| **T2I-02** | 基于取色值生图 | 用户点击"基于此颜色生成"，将当前取出的颜色值（如 #FF6B6B）拼接为 Prompt（如 "A beautiful abstract gradient background with dominant color #FF6B6B"），调用外部 API 生成图片 | **P1** |
| **T2I-03** | 图片比例选择 | 生成前支持选择 1:1、16:9、4:3 等常见比例 | **P1** |

#### 2.2.2 色彩语义理解（Color Semantics）

| 需求编号 | 功能点 | 详细描述 | 优先级 |
| --- | --- | --- | --- |
| **SEM-01** | 颜色情感解读 | 将取出的颜色值/图片整体色调发送给 LLM（如 GPT-4o/Claude/Gemini），生成一句色彩心理分析（如"这个暖橙色传递出活力与亲切感"） | **P0** |
| **SEM-02** | 配色建议对话 | 用户问"这个绿色搭配什么颜色好看？"，系统将颜色值 + 问题拼接为 Prompt，调用 LLM 返回搭配建议（互补色/类似色推荐） | **P1** |
| **SEM-03** | 图片风格标签化 | 上传图片后，调用多模态 LLM 自动生成 3-5 个色彩风格标签（如"复古胶片感"、"莫兰迪色系"、"高饱和对比"） | **P1** |

## 三、V1.0 技术架构要点（轻量化）

| 层级 | 组件 / 策略 | 说明 |
| --- | --- | --- |
| **前端（App/Web）** | React Native / Uni-app（跨端）或响应式 Web | 重点适配手机摄像头调用与触控取色交互 |
| **内部接口服务** | Python FastAPI + OpenCV + Colour-Science | 部署在公司自有服务器，处理校正/取值/比对，不依赖外网 |
| **外部接口网关** | 统一 API 网关（如阿里云 API 网关） | 管理文生图（通义万相/Midjourney 代理）和 LLM（GPT-4o/Gemini）的 Key、计费与限流 |
| **缓存策略** | Redis | 缓存同一张图片的取色结果，避免重复计算；缓存常用色名映射 |
| **数据库** | MySQL | 仅存储：取色历史记录、比对任务记录、用户上传原图（7 天自动清理） |

## 四、V1.0 端到端用户旅程（4 条核心路径）

**路径 A（取色 + 语义）**：打开相机/相册 → 点击取色 → 看到 HEX/RGB/Lab 值 → 点击"AI 解读" → 调用 LLM 返回情感描述。

**路径 B（比对）**：上传标准图 + 样品图（或拍照）→ 框选比对区域 → 计算 ΔE → 显示合格/不合格 + 热力图。

**路径 C（文生图）**：输入文字 / 基于取出的颜色 → 调用文生图 API → 生成图片 → 保存到本地。

**路径 D（图生文）**：输入图片 → 调用图生文 API → 生成文字 → 保存到本地。

## 五、V1.0 上线硬性验收标准（Go/No-Go）

| 维度 | 验收指标 | 达标线 |
| --- | --- | --- |
| 校色准确性 | 手机视觉校色至 80% 区域 ΔE < 2 | ΔE 平均值 ≤ 2.0 |
| 比对精度 | 相同图片多次比对，ΔE 波动范围 | ≤ ±0.5 |
| 接口可用性 | 内部接口（校正/取值/比对）可用率 | ≥ 99.5% |
| 外部接口容错 | 文生图/LLM 超时或报错时，前端有明确降级提示 | 不白屏，3 秒内返回 |
| 响应时间 | 取色响应 ≤ 1.5 秒；比对响应 ≤ 3 秒；文生图（不含排队）≤ 15 秒 | 达标率 ≥ 95% |
