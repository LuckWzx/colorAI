# 三、第二层：你的核心——Color Vision Agent

你负责的核心就是这个。

我建议暂时不要拆成很多 Agent。

```text
                    Color Vision Agent
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
     意图理解            任务规划             Tool Calling
        │                   │                   │
        └───────────────────┼───────────────────┘
                            │
                       结果处理
                            │
                       多轮上下文
```

它主要负责五件事情：

### 1. Intent Detection

判断用户想干什么：

```text
校色
取色
颜色转换
颜色比对
色彩分析
配色建议
文生图
图生文
```

---

### 2. Task Planning

判断是否需要多个 Tool。

例如：

> “帮我把这张照片校正一下，然后告诉我这个材料是什么颜色。”

规划：

```text
① color_correction
② color_picker
③ color_semantic
```

---

### 3. Tool Calling

真正调用：

```text
Python Tool
LLM Tool
Image Generation Tool
```

---

### 4. Result Understanding

Python 返回：

```text
ΔE = 2.3
```

Agent负责把它解释成用户能理解的信息：

> “两张图片平均色差为 ΔE2000 = 2.3，如果按照你设置的 2.0 阈值判断，则不合格。”

---

### 5. 多轮上下文

这是你做 Agent 最有价值的地方之一。

比如：

```text
用户：
帮我取一下这个颜色。

Agent：
#A86B42

用户：
这个颜色怎么样？

Agent：
这是偏暖的棕橙色……

用户：
那给我搭一个蓝色。

Agent：
基于刚才的 #A86B42……
```

Agent知道：

```text
current_color = #A86B42
```

所以后面的操作可以直接复用。

# 七、Tool ②：color_picker

输入：

```json
{
  "image": "...",
  "x": 350,
  "y": 520
}
```

Python返回：

```json
{
  "hex": "#A86B42",
  "rgb": {},
  "hsl": {},
  "lab": {}
}
```

PRD 要求取色后同时展示 HEX、RGB、HSL、CIE-Lab。

所以这里你们需要特别约定：

> **前端坐标 → 原始图片坐标**

例如：

```text
原图：
4000 × 3000

手机显示：
400 × 300

用户点击：
(100,150)

Python实际处理：
(1000,1500)
```

这个接口协议必须提前确定。

# 十二、哪些东西甚至不需要 Agent

这个边界你要明确：

| 功能                | 建议           |
| ----------------- | ------------ |
| 手机颜色校正            | Tool         |
| 单点取色              | Tool         |
| RGB/HEX/HSL/Lab转换 | Tool/普通API   |
| 取色历史              | 普通业务功能       |
| ΔE计算              | Tool         |
| ROI计算             | Tool         |
| 色差热力图             | Tool         |
| 颜色情感解读            | Agent/LLM    |
| 配色建议              | Agent/LLM    |
| 图片风格标签            | Agent/VLM    |
| 文生图               | Agent + Tool |
| 图生文               | Agent + Tool |

所以你的项目其实是：

> **Agent + Tools + AI Model + CV Service**

而不是：

> **一堆 Agent。**
